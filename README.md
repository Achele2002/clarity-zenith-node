# ZenithNode
A lightweight blockchain node contract for developers to run and manage nodes on the Stacks network.

## Features
- Node registration and management
- Node status tracking
- Node rewards distribution
- Node performance metrics
- Node staking capabilities
- Secure stake withdrawal with cooldown period

### Stake Withdrawal Process
1. Initiate withdrawal using `initiate-withdrawal`
2. Wait for cooldown period (100 blocks)
3. Complete withdrawal using `complete-withdrawal`
